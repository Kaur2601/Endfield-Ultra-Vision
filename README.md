## 🚀 Getting Started (Quick Setup)

1. **Extract the Archive:** Drag the entire `AstralForge` folder onto your Desktop. Ensure the game executable is fully closed.
2. **Deploy the Overlay:** Run the `AstralForge_Loader.exe` once. It will silently pair with the `EndfieldHorizons.exe` process.
3. **Confirm the Console:** Launch the game and press `F10`. The holographic wheel should fuse to your reticle.
4. **Toggle & Customize:** Turn on "Phase Shift" and walk through the starting gate wall just to test the response. Adjust the slider settings for Multi-Strike Echo to 3x for a balanced feel.

> **Pro Tip:** Use `Skip Narrative` during the prologue, then turn it off for the main storyline to stay immersed.

## 📚 FAQ (Frequently Asked Questions)

**Q: Will this trigger an anti-cheat?**
A: The tool runs strictly in kernel-user mode with no write operations to the game's persistent save file hashes. However, any active anti-cheat that monitors same-process injection *might* flag it. We recommend air-gapping your network connection to the game launcher while using the tool.

**Q: Does it work on the console edition?**
A: No. This build is exclusive to the PC architecture. No alternatives are planned for the current generation.

**Q: How do I remove the tool?**
A: Simply delete the `AstralForge` folder and close the game. The tool writes a dynamic log file, but it cleans up behind itself upon exit. No leftover `.dll` files remain in the game root directory.
